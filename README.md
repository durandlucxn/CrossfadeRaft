# CrossfadeRaft

CrossfadeRaft is a distributed system for real-time audio processing, leveraging auto-scaling architecture for concurrent sound blending.

With CrossfadeRaft, you get a lightweight tool that stays out of your way.

**What you get**

- CrossfadeRaft is a distributed system
- for real-time audio processing, leveraging
- auto-scaling architecture for concurrent sound

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/CrossfadeRaft.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

CrossfadeRaft is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
